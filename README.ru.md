## 🚀 Возможности

| Фича | Описание |
|---|---|
| 🎬 **YouTube** | Поиск по названию или воспроизведение по прямой ссылке через yt-dlp |
| 📻 **Radio** | Интерактивный поиск по 30 000+ станциям через API `radio-browser.info` |
| 📁 **Локальная библиотека** | Стриминг аудиофайлов из папки на сервере |
| 📋 **Серверные плейлисты** | Общие плейлисты гильдии с персистентностью в SQLite (переживают перезапуск) |
| 🔗 **Режим «По цепочке»** | Бот сам подбирает похожие треки, когда очередь закончилась |
| 🔊 **Автовыравнивание громкости** | `dynaudnorm` (FFmpeg) приводит все источники к единому уровню + ручная регулировка `/volume` |
| 🎛 **Умный плеер** | 9 кнопок: prev/play/skip/shuffle/repeat/queue/playlists/volume/stop |
| 🖥 **Docker & Healthcheck** | Автоперезапуск при падении, healthcheck проба, watchdog при зависании |
| 🔐 **Безопасность** | Защита от path traversal, параметризованные SQL-запросы, проверка владельца в select-меню |

## ⚙️ Установка

### Локально

Требования: **Python 3.10+**, [FFmpeg](https://ffmpeg.org/download.html).

```bash
git clone https://github.com/your-username/music_mitya_bot.git
cd music_mitya_bot

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Docker (рекомендуется)

FFmpeg уже настроен в образе.

```bash
docker compose up -d --build
```

## 📝 Конфигурация

Создай файл `.env` в корне проекта:

```env
TOKEN=твой_токен_бота
MUSIC_FOLDER=./music_library
# SYNC_GUILD_ID=123456789  # ID гильдии для мгновенной синхронизации слеш-команд
```

Технические параметры FFmpeg и фильтр нормализации настраиваются в `config.py`.

> ⚠️ **Слеш-команды не появились?** Discord кеширует глобальные команды до 1 часа.
> Укажите `SYNC_GUILD_ID=<id вашего сервера>` в `.env` — команды появятся мгновенно.
> Или просто подождите ~1 час / перезайдите в Discord (Ctrl+R).

## 📋 Интерактивное меню плейлистов

Команда **`/playlist`** открывает панель управления серверными плейлистами — всё через кнопки, без запоминания команд:

```
📋 Меню плейлистов
━━━━━━━━━━━━━━━━━━━━
• Ностальгия
• Chill Music
• Утренний плейлист

[📋 Список] [▶️ Играть] [➕ Создать]
[🍕 Добавить трек] [🗑 Удалить] [🚪 Закрыть]
```

| Кнопка | Что делает |
|---|---|
| **📋 Список** | Показать треки выбранного плейлиста (пагинация, удаление по номеру) |
| **▶️ Играть** | Выбрать плейлист → поставить в очередь |
| **➕ Создать** | Создать новый плейлист (модалка ввода имени) |
| **🍕 Добавить трек** | Добавить трек в плейлист (модалка: имя плейлиста + название/ссылка) |
| **🗑 Удалить** | Удалить плейлист (с подтверждением) |
| **🚪 Закрыть** | Закрыть меню |

Внутри списка треков: **◀️ ▶️** — страницы, **🗑 Удалить №** — модалка удаления по номеру, **🚪 Назад** — возврат в меню.

> **Совет:** старые команды `/playlist ...` тоже продолжают работать для «быстрых» действий.

## 🎛 Интерактивный плеер

При запуске любого трека появляется панель управления (3 ряда, 14 кнопок):

```
⏮️ ⏯️ ⏭️ 🔀 🔁    ← предыдущий / пауза / скип / перемешать / повтор (off·one·all)
🔗 📜 📋          ← цепочка / очередь (пагинация) / плейлисты
⏩ ⏭ 🔊 🌐 ⏹️    ← перемотка / скип N / громкость / язык / стоп
```

- Радио-пауза эмулируется (стоп + реинсерт в голову очереди)
- Повтор игнорируется для бесконечных радио-потоков
- Кнопки плеера доступны всем участникам гильдии; select-меню — только инициатору
- Когда очередь закончилась, появляется мини-панель: 🔗 цепочка / ▶️ повторить / ⏹️ стоп

## 🗄 Персистентность (SQLite)

| Данные | Хранилище | Переживает рестарт |
|---|---|---|
| Плейлисты и треки | `data/bot.db` (SQLite, WAL) | ✅ |
| Настройки гильдии (volume, chainplay, repeat) | `data/bot.db` (guild_settings) | ✅ |
| Очередь, таймеры, стек предыдущих | in-memory | ❌ (ожидаемо) |

## 🖥 Docker и живучесть

| Механизм | Назначение |
|---|---|
| `restart: unless-stopped` | Перезапуск при падении процесса |
| `HEALTHCHECK` | Проба `/tmp/bot_health` (обновляется каждые 30с) |
| `watchdog_loop` | Само-завершение при зависшем event loop |
| Volume `./data` | Персистентность БД |
| Volume `./music_library` | Локальные аудиофайлы |

├── main.py               # Точка входа, healthcheck, watchdog
├── docs/                 # Архитектура, контракт очереди, плеер, деплой
└── docker-compose.yml    # Деплой
